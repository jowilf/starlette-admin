# Examples

Runnable demos that cover starlette-admin's features end-to-end.
Each example is self-contained; most seed sample data automatically on the first run.

## Prerequisites

All examples use [uv](https://docs.astral.sh/uv/) for dependency management.

```bash
cd examples/<name>
uv run app.py
```

Then open <http://localhost:8000/admin/>.
