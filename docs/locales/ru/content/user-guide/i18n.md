# Интернационализация и часовые пояса

С помощью starlette-admin вы можете локализовать строки интерфейса для каждого пользователя и преобразовывать отображаемые дату и время в часовой пояс зрителя — независимо от того, как они хранятся в вашей базе данных.

> **Полный пример:** готовое работающее приложение, демонстрирующее интернационализацию и работу с часовыми поясами, находится в каталоге [examples/10-i18n-timezone](https://github.com/jowilf/starlette-admin/tree/main/examples/10-i18n-timezone) репозитория на GitHub.


## Установка дополнения `i18n`

Для поддержки перевода требуется [Babel](https://babel.pocoo.org/). Без него панель администрирования продолжает работать, но возвращается к английскому языку и пропускает форматирование дат и чисел с учётом локали.

=== "pip"
    ```bash
    pip install "starlette-admin[i18n]"
    ```

=== "uv"

    ```bash
    uv add "starlette-admin[i18n]"
    ```

## Установка локали

```python
from sqlalchemy import create_engine
from starlette_admin import I18nConfig
from starlette_admin.contrib.sqla import Admin
from starlette_admin.i18n import SUPPORTED_LOCALES

engine = create_engine("sqlite:///admin.sqlite")

admin = Admin(
    engine,
    title="My Admin",
    i18n_config=I18nConfig(
        default_locale="en",
        language_switcher=SUPPORTED_LOCALES,
    ),
    secret_key="a-long-random-string",
)
```

По умолчанию `i18n_config` равен `None` — в этом случае панель администрирования работает на английском языке. Если передать `I18nConfig`, панель устанавливает `LocaleMiddleware`. Это middleware определяет локаль при каждом запросе и предоставляет её шаблонам, а также функциям перевода (`gettext` и `lazy_gettext`) во всём коде полей и представлений.

Параметр `language_switcher` добавляет выпадающий список в навигационную панель, чтобы пользователи могли выбрать свою локаль. Оставьте значение по умолчанию `None`, чтобы скрыть переключатель и полагаться на `default_locale` и определение локали для каждого запроса.

### Справочник `I18nConfig`

| Атрибут | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `default_locale` | `str` | `"en"` | Локаль, используемая, когда ни cookie, ни заголовок не совпадают с поддерживаемой локалью. |
| `language_cookie_name` | `str | None` | `"language"` | Cookie, из которого считывается локаль пользователя. Установите `None`, чтобы отключить. |
| `language_header_name` | `str | None` | `"Accept-Language"` | Заголовок, который считывается при отсутствии cookie. Установите `None`, чтобы отключить. |
| `language_switcher` | `list[str] | None` | `None` | Локали, доступные в переключателе навигационной панели. Значение `None` скрывает переключатель. |

## Как определяется локаль

`LocaleMiddleware` определяет локаль один раз за запрос в следующем порядке:

1. **Cookie:** значение `language_cookie_name`, если оно соответствует одной из встроенных поддерживаемых локалей.
2. **Заголовок:** заголовок `Accept-Language` или заголовок, указанный в `language_header_name`, с той же проверкой корректности.
3. **По умолчанию:** `default_locale`, когда не совпадают ни cookie, ни заголовок.

Встроенные поддерживаемые локали (`starlette_admin.i18n.SUPPORTED_LOCALES`) — немецкая, английская, французская, португальская, русская, турецкая, а также китайская упрощённая и традиционная. Когда пользователь выбирает язык в навигационной панели, переключатель записывает cookie с языком, поэтому выбор сохраняется между запросами без серверного хранилища сессий.

## Часовые пояса

```python
from sqlalchemy import create_engine
from starlette_admin import TimezoneConfig
from starlette_admin.contrib.sqla import Admin

engine = create_engine("sqlite:///admin.sqlite")

admin = Admin(
    engine,
    title="My Admin",
    timezone_config=TimezoneConfig(
        default_timezone="UTC",
        database_timezone="UTC",
        timezone_switcher=["UTC", "Europe/Paris", "America/New_York", "Asia/Tokyo"],
    ),
    secret_key="a-long-random-string",
)
```
!!! note
    В отличие от `i18n_config`, параметр `timezone_config` по умолчанию не равен `None`. Если его не указать, класс `Admin` сам создаст `TimezoneConfig()`, поэтому преобразование часовых поясов включено сразу после установки. Панель администрирования считает даты и время без информации о часовом поясе (naive) значениями в `database_timezone`, который по умолчанию равен `"UTC"`, и показывает их каждому пользователю в `"UTC"` — значении `default_timezone` по умолчанию, — если пользователь не выбрал другой пояс.

### Как определяется часовой пояс

`TimezoneMiddleware` определяет часовой пояс один раз за запрос:

1. **Cookie:** значение `timezone_cookie_name`, которое по умолчанию равно `"timezone"`, если оно присутствует.
2. **По умолчанию:** иначе используется `default_timezone`.

Переключатель часового пояса в навигационной панели записывает этот cookie точно так же, как переключатель языков. Для часовых поясов нет аналога заголовка `Accept-Language`, потому что браузеры его не отправляют, поэтому определение полностью опирается на cookie. Обычно cookie устанавливает клиентский JavaScript, который читает `Intl.DateTimeFormat().resolvedOptions().timeZone`; то же делает и сам переключатель.

### Как преобразуются значения полей

`DateTimeField` и `ArrowField` преобразуют значения между `database_timezone` и часовым поясом, определённым для зрителя.

* **Чтение (страница списка, страница деталей, экспорт):** панель администрирования считает значение без часового пояса из вашей базы данных значением в `database_timezone` и преобразует его в часовой пояс зрителя перед форматированием.
* **Запись (формы создания и редактирования):** панель администрирования считает отправленное значение значением в часовом поясе зрителя и преобразует его в `database_timezone` до того, как оно попадёт в вашу модель.

В результате два администратора в разных часовых поясах могут редактировать одну и ту же строку, каждый видит время в своём местном времени, а база данных хранит всё в едином согласованном часовом поясе.

### Справочник `TimezoneConfig`

| Атрибут | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `default_timezone` | `str` | `"UTC"` | Часовой пояс, используемый, когда cookie не установлен. Принимает любое имя часового пояса IANA. |
| `timezone_cookie_name` | `str | None` | `"timezone"` | Cookie, из которого считывается часовой пояс зрителя. Установите `None`, чтобы отключить. |
| `database_timezone` | `str` | `"UTC"` | Часовой пояс, в котором предполагается хранение ваших дат и времени. |
| `timezone_switcher` | `list[str] | None` | `None` | Часовые пояса, доступные в переключателе навигационной панели. Значение `None` скрывает переключатель. |
| `use_user_locale_timezone` | `bool` | `True` | Предпочитать часовой пояс, определённый по локали пользователя, значению `default_timezone`. |

Чтобы ограничить выбор пользователей, передайте более короткий список `timezone_switcher`. Чтобы принудительно задать один часовой пояс для всех зрителей, установите `timezone_switcher` в `None` и укажите `default_timezone` напрямую, например на общекорпоративный `"Europe/Paris"`.

Переключатель в навигационной панели отображает название каждого часового пояса и смещение UTC с помощью глобальных переменных шаблонов `get_timezone` и `get_timezone_display_name`. Эти и все остальные глобальные переменные описаны в руководстве [Шаблоны](../advanced/templates.md).
