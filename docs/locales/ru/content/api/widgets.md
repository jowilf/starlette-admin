# Виджеты

Полный справочник атрибутов и методов системы виджетов, сгенерированный из докстрингов. Пошаговое руководство по практическим задачам см. в разделах [Пользовательские представления и виджеты](../user-guide/custom-views.md) и [Компоновка форм](../advanced/form-layout.md).

Виджеты — это составные отображаемые строительные блоки, используемые для динамического построения элементов интерфейса. Каждый класс виджетов, перечисленный ниже, можно импортировать напрямую из `starlette_admin`.

Система виджетов выполняет две основные роли в зависимости от контекста:

* **Дашборды и пользовательские страницы:** используется как атрибут `widget` у [`CustomView`](views.md#starlette_admin.views.CustomView) для построения автономных интерфейсов и панелей метрик.
* **Компоновка форм:** используется как атрибут `form_layout` у [`BaseModelView`](views.md#starlette_admin.views.BaseModelView) для упорядочивания и группировки полей ввода на формах создания и редактирования.

## Контентные виджеты

Контентные виджеты выступают листовыми узлами вашего дерева интерфейса. Вместо хранения других виджетов они отображают актуальные данные. Каждый контентный виджет принимает асинхронную функцию обратного вызова, которая вызывается один раз за запрос — это гарантирует, что отображаемые значения всегда актуальны.

## Компоновочные виджеты

Компоновочные виджеты — это контейнеры, используемые для упорядочивания их `children` (которыми могут быть контентные виджеты, поля формы или другие компоновочные виджеты).

**Автоматическое управление ресурсами:** компоновочные виджеты рекурсивно обходят своё дерево, чтобы собрать `additional_css_links` и `additional_js_links` у дочерних элементов. Благодаря этому глубоко вложенные компоненты автоматически загружают необходимые ресурсы CSS/JS без ручной настройки.

## Сокращённая запись и нормализация

Чтобы код компоновки оставался чистым и легко читаемым, контейнерные виджеты принимают обычные типы Python вместо явного создания экземпляров классов виджетов. При инициализации (`__post_init__`) контейнеры автоматически преобразуют эти сокращённые значения в соответствующие им виджеты.

**Поддерживаемые сокращения:**

* `str`: преобразуется в ссылку на поле (`FieldRef`).
* `tuple`: преобразуется в горизонтальный ряд (`RowWidget`).
* `list`: преобразуется в вертикальную стопку (`ColumnWidget`).

::: starlette_admin.widgets.WidgetShorthand
::: starlette_admin.widgets.normalize_widget
