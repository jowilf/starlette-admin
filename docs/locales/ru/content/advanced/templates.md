# Шаблоны

Каждая страница панели администрирования — это шаблон Jinja2, который вы можете переопределить. Измените одну страницу списка, ячейку таблицы для одного поля или виджет дашборда, не создавая форк встроенного дерева шаблонов.

## Как работает загрузчик шаблонов

```python
from sqlalchemy import create_engine
from starlette_admin.contrib.sqla import Admin

engine = create_engine("sqlite:///admin.sqlite")
admin = Admin(engine, title="My Admin", templates_dir="my_templates/")
```

`Admin` создаёт Jinja2 `ChoiceLoader`, который сначала проверяет ваш `templates_dir`, а затем встроенный каталог пакета `starlette_admin/templates/`. Поместите файл в `my_templates/` по тому же относительному пути, что и внутри `starlette_admin/templates/`, — и ваш файл перекроет встроенный. Все остальные шаблоны продолжат рендериться из встроенного каталога.

!!! note
    В цепочку загрузчиков также регистрируется `PrefixLoader` под ключом `@starlette-admin`, который всегда указывает на встроенные шаблоны независимо от того, что их перекрывает в `templates_dir`. Обращайтесь к ним по формату пути `@starlette-admin/<name>.html`, не добавляя косую черту в конце самого префикса. Зачем это нужно, описано ниже в разделе [Переопределение шаблона одной страницы](#overriding-a-single-page-template).

## Карта каталога шаблонов

| Путь | Для чего используется |
| --- | --- |
| `base.html` | Внешняя HTML-разметка (`<html>`, `<head>`, скрипты) |
| `layout.html` | Боковая панель и верхняя панель (расширяет `base.html`) |
| `index.html` | Дашборд или домашняя страница |
| `list.html` | Страница списка модели (таблица, панель фильтров, пагинация) |
| `detail.html` | Страница деталей (только чтение) одной записи |
| `create.html` | Форма создания |
| `edit.html` | Форма редактирования |
| `login.html` | Страница входа |
| `error.html` | Страница HTTP-ошибки (403, 404 и т. д.) |
| `actions.html` | Модальное окно групповых действий |
| `row-actions.html` | Выпадающий список действий над строкой |
| `inline.html` | Инлайн-форма на странице создания и редактирования |
| `inline_detail.html` | Инлайн-таблица на странице деталей |
| `inline_row.html` | Одна строка внутри инлайн-формы |
| `_filter_bar.html` | Панель активных фильтров над списком |
| `_filter_builder.html` | Модальное окно конструктора фильтров |
| `_pagination.html` | Элементы управления пагинацией |
| `_column_header.html` | Ячейка заголовка сортируемого столбца |
| `_form_footer.html` | Кнопки «Сохранить», «Сохранить и продолжить» или «Добавить ещё» |
| `_form_group.html` | Fieldset одной группы [компоновки формы](form-layout.md) на форме создания и редактирования |
| `_form_group_fields.html` | Поля ввода, отрисованные внутри группы компоновки формы |
| `fields/list/<type>.html` | Ячейка столбца списка для типа поля |
| `fields/detail/<type>.html` | Отображение поля на странице деталей |
| `fields/form/<type>.html` | Виджет ввода формы для типа поля |
| `widgets/<name>.html` | Шаблон виджета дашборда |
| `modals/actions.html` | Модальное окно подтверждения действия |
| `modals/delete.html` | Модальное окно подтверждения удаления |
| `modals/error.html` | Модальное окно ошибки |
| `modals/import.html` | Модальное окно импорта |
| `macros/views.html` | Общие макросы Jinja2, используемые на разных страницах |

!!! note
    Встроенное дерево также содержит `modals/loading.html` — универсальное модальное окно состояния загрузки — и несколько шаблонов для конкретных типов полей в каталогах `fields/list/`, `fields/detail/` и `fields/form/`. Прежде чем переопределять универсальный файл `<type>.html`, проверьте точные имена файлов в `starlette_admin/templates/` для установленной у вас версии.

## Переопределение шаблона одной страницы {#overriding-a-single-page-template}

```
my_templates/
└── list.html   ← перекрывает встроенный list.html

```

```jinja
{# my_templates/list.html #}
{% extends "@starlette-admin/list.html" %}

{% block content %}
  <div class="alert alert-info">Пользовательский баннер над списком.</div>
  {{ super() }}
{% endblock %}

```

Запись `{% extends "list.html" %}` снова привела бы к вашему собственному `my_templates/list.html`, потому что `templates_dir` проверяется первым, а такая циклическая ссылка вызывает ошибку бесконечной рекурсии. Префикс `@starlette-admin/` всегда указывает на встроенную копию, поэтому каждое `extends` и `include` внутри переопределения должно использовать его вместо простого имени файла.

## Переопределяемые блоки

Каждая встроенная страница расширяет `layout.html`, который в свою очередь расширяет `base.html`. Чтобы изменить один фрагмент страницы без дублирования остального содержимого, переопределите отдельный `{% block %}`, а не целый файл:

```jinja
{# my_templates/list.html #}
{% extends "@starlette-admin/list.html" %}

{% block list_toolbar_extra %}
  {{ super() }}
  <a class="btn btn-outline-primary" href="/reports/export">Пользовательский отчёт</a>
{% endblock %}

```

### Пример: замена логотипа в боковой панели на инлайн-SVG

Передача URL в `Admin(logo_url=...)` — самый быстрый способ задать логотип, и он покрывает большинство случаев, включая внешние `.svg`-файлы. Однако встроенный шаблон отрисовывает этот URL внутри тега `<img>`, поэтому SVG не может наследовать CSS-свойства окружающей страницы.

Переопределите блок `brand` **инлайн-разметкой `<svg>`**, если нужно, чтобы логотип реагировал на оформление остального интерфейса.

#### Реализация

Создайте файл `layout.html` в каталоге ваших шаблонов. Каждая страница панели администрирования наследуется от `layout.html`, поэтому одно это переопределение действует на всём сайте.

```jinja
{# my_templates/layout.html #}
{% extends "@starlette-admin/layout.html" %}

{% block brand %}
  <svg class="navbar-logo" viewBox="0 0 32 32" fill="currentColor">
    <path d="M16 2 L30 9 L30 23 L16 30 L2 23 L2 9 Z" />
  </svg>
{% endblock %}

```

!!! tip "Сохраняйте класс navbar-logo"
    Оставьте CSS-класс `navbar-logo` на вашем элементе `<svg>`. Он придаёт вашей инлайн-графике выравнивание, внутренние отступы и размеры фреймворка без единой строки собственного CSS.

## Переопределение шаблонов полей

Для контекста каждого поля используются три подкаталога:

| Каталог | Где используется |
| --- | --- |
| `fields/list/<type>.html` | Ячейка таблицы списка (компактная, только чтение) |
| `fields/detail/<type>.html` | Отображение на странице деталей (полное, только чтение) |
| `fields/form/<type>.html` | Поле ввода в форме создания и редактирования |

Вы можете переопределить ячейку списка для текстовых полей, не затрагивая форму и страницу деталей:

```
my_templates/
└── fields/
    └── list/
        └── text.html

```

Чтобы указать одному **экземпляру поля** на ваш шаблон вместо переопределения типа везде, задайте атрибут `list_template`, `detail_template`, `form_template`, `null_template` или `empty_template` у самого поля:

```python
from starlette_admin.fields import StringField

StringField("status", list_template="fields/list/status_badge.html")
```

`null_template` (по умолчанию `"fields/detail/_null.html"`) и `empty_template` (по умолчанию `"fields/detail/_empty.html"`) — это отдельные слоты. Страницы списка и деталей отрисовывают их вместо `list_template` или `detail_template`, когда значение поля равно `None` либо является пустым списком или кортежем:

```python
StringField("status", null_template="fields/detail/_status_null.html")
```

## Переопределение шаблонов виджетов

Виджеты следуют тому же паттерну переопределения. Поместите свои файлы в каталог `widgets/`:

```
my_templates/
└── widgets/
    └── stat_widget.html

```

## Глобальные переменные шаблонов

Эти переменные доступны в каждом шаблоне без явной передачи. `Admin` устанавливает их как глобальные переменные Jinja2 один раз во время настройки:

| Переменная | Тип | Описание |
| --- | --- | --- |
| `views` | `list[BaseView]` | Все зарегистрированные представления (используются для отрисовки боковой панели) |
| `app_title` | `str` | Название панели администрирования (`Admin(title=...)`) |
| `is_auth_enabled` | `bool` | `True`, если настроен провайдер аутентификации |
| `__name__` | `str` | Префикс имени маршрутов панели администрирования (например, `"admin"`) |
| `static_url` | `callable` | `static_url(request, path, v=None)` → URL встроенного статического ресурса. Аргумент `v` добавляет параметр запроса `?v=` для сброса кеша. |
| `logo_url` | `callable` | `logo_url(request)` → URL логотипа в боковой панели или `None`, если он не задан |
| `login_logo_url` | `callable` | `login_logo_url(request)` → URL логотипа страницы входа или `None`, если он не задан |
| `favicon_url` | `callable` | `favicon_url(request)` → URL фавиконки или `None`, если она не задана |
| `list_url` | `callable` | `list_url(request, **overrides)` → URL с параметрами из `overrides`, объединёнными со строкой запроса (используется для ссылок сортировки, пагинации и поиска). Передайте `None`, чтобы удалить ключ. |
| `detail_url` | `callable` | `detail_url(request, key, pk)` → URL страницы деталей записи |
| `edit_url` | `callable` | `edit_url(request, key, pk)` → URL страницы редактирования записи |
| `export_url` | `callable` | `export_url(request, key, fmt)` → URL скачивания экспорта, несущий состояние фильтров, сортировки и поиска текущей страницы списка |
| `import_url` | `callable` | `import_url(request, key)` → POST-URL импорта |
| `get_locale` | `callable` | `get_locale()` → Строка активной локали (аргумент `request` не требуется) |
| `get_locale_display_name` | `callable` | `get_locale_display_name(locale)` → Понятное человеку название строки локали |
| `i18n_config` | `I18nConfig` | Объект конфигурации i18n панели администрирования |
| `get_timezone` | `callable` | `get_timezone()` → Строка активного часового пояса (аргумент `request` не требуется) |
| `get_timezone_display_name` | `callable` | `get_timezone_display_name(timezone, show_offset=False)` → Понятное человеку название строки часового пояса |
| `timezone_config` | `TimezoneConfig | None` | Конфигурация часового пояса панели администрирования |
| `theme_settings` | `TablerSettings` | Конфигурация активной темы Tabler (base, primary, radius, mode), предоставляемая `DefaultTheme` |
| `csrf_input` | `callable` | `csrf_input(request)` → Отрисовывает скрытый `<input>` CSRF |

!!! note
    `get_locale`, `get_locale_display_name`, `get_timezone` и `get_timezone_display_name` не принимают параметр `request`. Они читают локаль и часовой пояс из `contextvars`, которые `LocaleMiddleware` заполняет на время выполнения запроса, а не из объекта `Request`.

## Добавление собственных глобальных переменных и фильтров

Чтобы добавить в шаблоны собственные переменные и функции, создайте подкласс `Admin` и переопределите `__init__`. Сначала вызовите `super().__init__()`, чтобы `self.templates` существовал до ваших изменений:

```python
from sqlalchemy import create_engine
from starlette_admin.contrib.sqla import Admin


class MyAdmin(Admin):
    def __init__(self, *args, **kwargs) -> None:
        super().__init__(*args, **kwargs)
        self.templates.env.globals["site_name"] = "My App"
        self.templates.env.filters["currency"] = lambda v: f"${v:,.2f}"


engine = create_engine("sqlite:///admin.sqlite")
admin = MyAdmin(engine, title="My Admin")
```

## Встроенные фильтры Jinja2

Каждый экземпляр панели администрирования регистрирует эти фильтры во время `_setup_templates`:

| Фильтр | Сигнатура | Описание |
| --- | --- | --- |
| `is_custom_view` | `view | is_custom_view` | Возвращает `True`, если ресурс является `CustomView` |
| `is_link` | `view | is_link` | Возвращает `True`, если ресурс является `Link` |
| `is_model_view` | `view | is_model_view` | Возвращает `True`, если ресурс является `BaseModelView` |
| `is_dropdown` | `view | is_dropdown` | Возвращает `True`, если ресурс является `DropDown` |
| `tojson` | `value | tojson` | Безопасная для HTML сериализация в JSON (заменяет стандартный `tojson` из Jinja2) |
| `file_icon` | `mime_type | file_icon` | Возвращает полный класс иконки для MIME-типа (например, `application/pdf` → `fa-solid fa-fw fa-file-pdf`); переопределите `self.templates.env.filters["file_icon"]`, чтобы использовать свой набор иконок |
| `to_view` | `key | to_view` | Ищет зарегистрированный `BaseModelView` по строковому ключу; выбрасывает исключение 404 `HTTPException`, если ничего не найдено |
| `is_iter` | `value | is_iter` | Возвращает `True`, если значение является `list` или `tuple` |
| `is_str` | `value | is_str` | Возвращает `True`, если значение является `str` |
| `is_dict` | `value | is_dict` | Возвращает `True`, если значение является `dict` |
| `ra` | `value | ra` | Преобразует строку в член перечисления `RequestAction` |
| `safe_url` | `url | safe_url` | Возвращает URL, только если он проходит проверку безопасности, иначе возвращает `""` |
| `sanitize_html` | `html | sanitize_html` | Удаляет запрещённые теги из HTML-строки и возвращает `Markup` |
