# Точки расширения

На этой странице собраны все подключаемые поверхности `starlette-admin` в одном месте. Найдите класс, хук или декоратор, соответствующий тому, что вы хотите изменить, и перейдите по ссылке к полному руководству.

| Точка расширения | Интерфейс API или хук | Документация |
| --- | --- | --- |
| **Пользовательский фильтр** | Создайте подкласс `BaseFilter` и переопределите `get_filter_registry()` в `ModelView`. | [Пользовательские фильтры](custom-filters.md) |
| **Пользовательский экспортёр** | Создайте подкласс `BaseExporter`. | [Экспорт и импорт](../user-guide/export-import.md) |
| **Пользовательский импортёр** | Создайте подкласс `BaseImporter`. | [Экспорт и импорт](../user-guide/export-import.md) |
| **Пользовательская тема** | Создайте подкласс `BaseTheme`. | [Пользовательские темы](custom-themes.md) |
| **Пользовательский бэкенд аутентификации** | Создайте подкласс `BaseAuthProvider`. | [Аутентификация](../user-guide/auth.md) |
| **Пользовательское файловое хранилище** | Создайте подкласс `BaseStorage`, который регистрируется через свой атрибут `name`. | [Файловое хранилище](../user-guide/file-storage.md) |
| **Пользовательский виджет** | Создайте подкласс `BaseWidget`. | [Пользовательские представления](../user-guide/custom-views.md) |
| **Дополнительные маршруты в пользовательском представлении** | Примените декоратор `@route("/path", methods=["GET"])` к методу `CustomView`. | [Пользовательские представления](../user-guide/custom-views.md) |
| **Плагин** | Создайте подкласс `BasePlugin`, чтобы объединить поля, представления, ресурсы и многое другое. | [Плагины](plugins.md) |

!!! tip
    Чтобы изменить цвета темы Tabler по умолчанию, пользовательская тема не нужна. Вместо этого передайте объект `TablerSettings` в экземпляр `DefaultTheme`.
