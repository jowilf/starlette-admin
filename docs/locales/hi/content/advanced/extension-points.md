# एक्सटेंशन पॉइंट {#extension-points}

यह पेज `starlette-admin` की हर प्लग करने योग्य सतह को एक ही जगह सूचीबद्ध करता है। वह क्लास, हुक, या डेकोरेटर ढूँढें जो आपके बदलना चाहे चीज़ से मेल खाता हो, फिर पूरी गाइड के लिए लिंक पर जाएं।

| एक्सटेंशन पॉइंट | API इंटरफ़ेस या हुक | दस्तावेज़ |
| --- | --- | --- |
| **कस्टम फ़िल्टर** | `BaseFilter` को सबक्लास करें और `ModelView` पर `get_filter_registry()` को ओवरराइड करें। | [कस्टम फ़िल्टर](custom-filters.md) |
| **कस्टम एक्सपोर्टर** | `BaseExporter` को सबक्लास करें। | [एक्सपोर्ट और इंपोर्ट](../user-guide/export-import.md) |
| **कस्टम इंपोर्टर** | `BaseImporter` को सबक्लास करें। | [एक्सपोर्ट और इंपोर्ट](../user-guide/export-import.md) |
| **कस्टम थीम** | `BaseTheme` को सबक्लास करें। | [कस्टम थीम](custom-themes.md) |
| **कस्टम प्रमाणीकरण बैकएंड** | `BaseAuthProvider` को सबक्लास करें। | [प्रमाणीकरण](../user-guide/auth.md) |
| **कस्टम फ़ाइल स्टोरेज** | `BaseStorage` को सबक्लास करें, जो अपने `name` एट्रिब्यूट के ज़रिए खुद को रजिस्टर करता है। | [फ़ाइल स्टोरेज](../user-guide/file-storage.md) |
| **कस्टम विजेट** | `BaseWidget` को सबक्लास करें। | [कस्टम व्यू](../user-guide/custom-views.md) |
| **कस्टम व्यू पर अतिरिक्त रूट** | किसी `CustomView` मेथड पर `@route("/path", methods=["GET"])` डेकोरेटर लगाएं। | [कस्टम व्यू](../user-guide/custom-views.md) |
| **प्लगइन** | फ़ील्ड, व्यू, assets, और बहुत कुछ एक साथ बंडल करने के लिए `BasePlugin` को सबक्लास करें। | [प्लगइन](plugins.md) |

!!! tip
    डिफ़ॉल्ट Tabler थीम के रंग बदलने के लिए आपको कस्टम थीम की ज़रूरत नहीं है। इसके बजाय एक `DefaultTheme` इंस्टेंस में `TablerSettings` ऑब्जेक्ट पास करें।
