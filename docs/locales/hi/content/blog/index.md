# डेवलपर ब्लॉग {#developer-blog}

यह सेक्शन `starlette-admin` के साथ एडमिन इंटरफ़ेस बनाने के लिए एडवांस पैटर्न और व्यावहारिक तकनीकें प्रस्तुत करता है। ये आर्टिकल मानक रेफ़रेंस डॉक्यूमेंटेशन से आगे बढ़कर वास्तविक दुनिया के इम्प्लीमेंटेशन पर केंद्रित हैं।

## नई पोस्ट प्रकाशित करना {#publishing-a-new-post}

Zensical प्लेटफ़ॉर्म अभी ब्लॉग कंटेंट के लिए मैन्युअल रूप से मैनेज किए जाने वाले स्टैटिक इंडेक्स पर निर्भर करता है। कोई नया आर्टिकल प्रकाशित करने के लिए निम्नलिखित चरण पूरे करें:

1. **कंटेंट बनाएँ:** अपनी पोस्ट लिखें और Markdown फ़ाइल को `blog/posts/` डायरेक्टरी के अंदर सेव करें।
2. **इंडेक्स अपडेट करें:** नीचे **प्रकाशित आर्टिकल** टेबल में एक नई रो जोड़ें, जिसमें प्रकाशन की तारीख़ और आपकी फ़ाइल का रिलेटिव लिंक शामिल हो।
3. **कॉन्फ़िगरेशन अपडेट करें:** नए पोस्ट का पाथ `zensical.toml` फ़ाइल में रजिस्टर करें।
